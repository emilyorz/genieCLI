# Experiments

One-off test scripts and experiments. Not part of the test suite.

Run the real test suite with `pytest tests/` from the project root.

## Files

- `test_startup.py` — Basic startup logging experiment
- `test_startup_interact.py` — Interactive startup test
- `test_trino_research.py` — Trino optimization loop experiment
- `test_autoresearch.py` — Autoresearch feature experiment
- `tmp-loop.py` — Temporary loop test
- `exp_truncation.py` — Truncation behavior test
